# Data Science Project: Rio 2016 Olympics Medal Analysis

## 1. The problem or research question
This project investigates the relationship between the number of participating athletes and the total medal count across different countries in the Rio 2016 Olympic Games.

## 2. Dataset source and usage permissions
- Dataset: `olympia2016_athletes.csv`
- Source: Collected from public sports data repositories for academic coursework purposes (CISC7204).

## 3. Methods and tools used
- **Python (Pandas)**: Data cleaning, aggregation, and grouping.
- **Bokeh & ipywidgets**: Building interactive visualizations and dynamic filtering sliders.

## 4. Key findings and one limitation
- **Key findings**: Countries with larger athletic delegations generally accumulate more total medals, showing a clear positive scaling effect.
- **Limitation**: The dataset focuses only on aggregate medal counts and does not adjust for population size or national GDP per capita.

## 5. Instructions for running the analysis
1. Clone the repository: `git clone https://github.com/LIJIAMAN57/data-science-project.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the Jupyter Notebook to explore the interactive visual dashboard.
